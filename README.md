# gamesworkshop

Games about evidence, decisions and consequences.

## Summit

```sh
./run-summit.sh
```

Requires Linux and Python 3. The launcher restarts the Summit server. Ctrl+C to kill.

Open the [landing page](http://localhost:8688/) for **Sentences**, **Rover** and
**Households**. Share the printed `/audience` link with the room.
