Read the paper, then choose what to reveal

Some sheets say HAZE -> FULL / vote 1 BATTERY.
Other sheets say HAZE -> STORM / vote 3 DUST.
Both observations are possible under the same model—even in the same historical case.
If the rep flips battery: it is full in square 2. That does not clear the weather.
If the rep flips dust: STORM is visible, so AVOID is justified.
The battery is dead in square 3, immediately after the hazard. Recharge before moving on.

Sudden death makes both errors matter

GO into SAND or STORM: the run ends.
AVOID a safe square: the run also ends.
Move on a dead battery: the run ends. Recharge first.
Illustrated valid model sequence, not one of the four sealed routes.
In frozen Rover Run, battery also dies after SAND. The false-avoid death is new to this extension.
