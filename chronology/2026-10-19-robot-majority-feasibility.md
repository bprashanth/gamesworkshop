# Robot majority word experiment before printing

User asked whether majority voting from Swift-format sheets can produce a
well-formed robot sentence, followed by a separate audience-written pivot.
Requested simulations before answers/PDF generation.

Created isolated paperweights/robot-majority lab. Executed old corpus baseline,
robot corpus with uncolored keys, and the same corpus with contextual colors.
Old majority walks usually cycle; uncolored robot walk forms a fragment.
Context-colored grammar yields a complete robot sentence in every full-room
majority run across 100 deals each at 15/100/200 sheets. Sampling also completes
inside the authored grammar. Every allowed edge advances a phase, so supported
paths terminate after 14 choices. This is an authored guarantee, not grammar
learned from unrestricted prose. Actual sheets have 24 unique-left-cue rows.

Canonical output: One night the old man found his robot checking every boat by
the harbour. A paired reweighting toward sinking changes that action at the
same majority rule. Live pivot ballots remain a worked example, not collected
human responses. Framing and crowd enjoyment have not been empirically tested.

No PDFs generated, no household reverse-side encoding claimed, no game or server
changed. Generated corpus/deals/full traces remain ignored local artifacts;
scripts and narrative reproduce them. Narrative: narrative/ROBOT_MAJORITY.md.
