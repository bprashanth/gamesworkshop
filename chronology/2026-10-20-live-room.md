# Live room: landing page, phones and votes

User asked for a landing page with the running order (Sentences, Rover Risks,
Rover collaborative Easy, Households Indicators, Icons) and an audience page on
phones for sheets and votes, with bots to fill the room.

Built `paperweights/room/` (server on 8688, separate from the 8684 static site).
Majority word, Rover Risks Go/Avoid and Households flip suggestions now take live
ballots; the host accepts by eye while counts rise. Static 8684 behaviour is unchanged.

Played as host and phones in a browser with bots. A first Rover run lost a team on a
safe steep screen: per-seat random decoys gave one team 4/10 steep sheets. Decoys and
household noise are now stratified within each team. Replays: all four Rover teams
finish when the rep waits for ~60% of votes. Households: AI alone 0/4 finish on seed 15;
with audience flips about half. [Details](../paperweights/room/README.md).
